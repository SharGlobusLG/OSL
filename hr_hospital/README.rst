HR Hospital
===========

Module capabilities
-------------------

* This module enables record-keeping for a small medical facility.
* Tracking of doctors and their qualifications.
* Patient records.
* Tracking of patient appointments/consultations.
* Display appointments statistic as chart.

Installation
============

To install this module, you need to:

#. Clone repository.
#. Add the repository path to the config file.
#. Update the app list.
#. Install the module.
